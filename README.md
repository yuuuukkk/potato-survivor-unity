# 土豆幸存者

一款个人主导设计与迭代的 Unity 2D 俯视角生存游戏。玩家负责走位，武器自动寻找目标；每波通过战斗获取经验和材料，波末选择强化，并在商店购买、合成武器和安排构筑。项目以《土豆兄弟》等幸存者游戏为玩法参考，是非官方练习作品，与原作没有关联。

当前仓库是**游戏工程源码，不是安装包**。默认 20 波，包含角色选择、升级、三商品位商店、武器出售与合成、独立武器构筑、Boss 和可选挑战。项目重点是波次节奏与逐把武器构筑：构筑先在商店解锁，再按武器等级配置基础槽位及支线。数值、表现和不同屏幕比例下的界面仍在调整；“已实现”只表示代码和资源已接入，不代表所有组合都已完成 Unity Play 验收。

## 打开与游玩

1. 安装 Unity **2022.3.20f1c1**（项目记录的版本；同系列 2022.3 LTS 可能需要重新导入）。
2. 在 Unity Hub 中选择本仓库的 `UnityProject` 文件夹。首次导入请等待 Unity 解析资源和脚本。
3. 打开 `UnityProject/Assets/_Game/scene/rouge.unity`，点击 **Play**。该场景已列入 Build Settings；不需要手动新建场景或逐个挂载素材。
4. 在主菜单选角色并开始游戏。键盘用 **WASD / 方向键**移动，武器自动攻击；**Esc** 打开或关闭设置，**F1** 显示测试用 GM 面板。手机运行时显示触控摇杆。

要制作可分发版本，请在 Unity 的 **File → Build Settings** 中选择 Windows 或 Android 后构建。Windows 构建需要把 `.exe` 和同名 `_Data` 文件夹一起交给朋友；Android 构建需要安装与该 Unity 编辑器版本对应的 Android Build Support 模块。仓库未附带预构建的 EXE/APK。

## 当前玩法

- 三名角色：土豆农夫、辣椒小子、蘑菇法师。角色有各自的初始武器、可用武器类别和武器槽限制。
- 武器涵盖枪械、近战、回旋镖与无人机等；怪物死亡掉落经验与材料，升级时选择强化，波次之间进入商店。
- 商店一次显示 **3 个商品位**，可刷新、锁定商品、购买道具或武器，并出售持有武器。同等级武器的合成与各角色武器槽限制由游戏逻辑处理。
- 构筑在商店先购买基础、再解锁并升级该基础下的支线；到独立的**“武器构筑”**界面逐把装备、逐把选路。武器几级就有几个基础构筑槽，支线不额外占槽；同型号武器共享购买记录但可以走不同路线。已有折射、魅惑、剑气、击杀掉落生机种和击杀成长等机制；目前四棵构筑树有二选一支线，其他基础构筑还在补支线。
- 波间挑战是可选内容；未配置在线 AI 时仍可使用本地挑战。游戏本体不依赖网络。
- Windows 设置界面提供分辨率和全屏选项；Android 为横屏、提供触控摇杆。画布使用 Unity Canvas Scaler 的 Expand 模式，界面和手机安全区仍需在实际设备上验收。GM 面板用于开发测试，不是正式游戏功能。

## 配置与素材在哪里

主要可编辑配置都在 `UnityProject/Assets/_Game/Resources/Config/`：

| 文件 | 内容 |
| --- | --- |
| `GameContent.asset` | 武器、武器改造、敌人、道具和挑战目录 |
| `CharacterRoster.asset` | 角色、初始武器与角色限制 |
| `GameBalance.asset` | 波次、商店、战斗反馈及全局数值 |
| `GameSettings.asset` | 场景、开局、手机触控及可选 AI 连接 |
| `UITheme.asset` | 界面主题 |

角色、敌人、武器、弹体、道具、特效和地图图片位于 `UnityProject/Assets/_Game/Resources/Art/`。场景和预制体位于 `UnityProject/Assets/_Game/scene/`、`UnityProject/Assets/_Game/Resources/Prefabs/`。替换素材时应保留 Unity 的 `.meta` 文件，并检查相应的 Sprite 导入、碰撞和预制体引用。旧 `Resources/Data/*.json` 是兼容回退路径；当前优先加载上述 SO 配置。

统一画风的道具、普通弹体、敌方弹体、Boss 动画和构筑效果在 `UnityProject/Assets/_Game/Resources/Art/` 下。击杀回血掉落是红色“生机种”，与商店急救包不同。整张透明图集保存在 `UnityProject/Tools/art_*_v2_atlas.png`，运行 `UnityProject/Tools/slice_unified_art_v2.py` 可重新裁切；保留同名 PNG 的 `.meta` 文件就不会丢失 Unity 引用。角色、怪物和武器的原造型保持不变，作为这套粗描边卡通风格的基准。

刷怪的初始预算、持续补充比例、间隔和场上上限在 `GameBalance.asset`；各怪首次出现波次与权重增长在 `GameContent.asset`。新构筑及后续候选见 [`docs/构筑扩展_成长与掉落.md`](docs/构筑扩展_成长与掉落.md)。

## 可选 AI 功能与密钥

AI 只会在游戏预设的挑战/改造候选中做推荐或选择，不会生成可执行代码，也不会自动改写武器数值。已上传的 Git 版本 `GameSettings.asset` 不含 API Key；本地工作区可能有测试密钥，发布源码或安装包前必须清除。未配置时可照常游玩及使用本地挑战。相关实现与本机代理说明见 [`docs/AI接入DeepSeek本机测试.md`](docs/AI接入DeepSeek本机测试.md)，但该文档记录了早期测试过程，具体按钮和候选数量请以当前游戏为准。

不要把真实密钥提交到 Git。把密钥直接填进 Unity 资源或安装包后，其他人可以从文件中提取；给朋友提供在线 AI 时应由你控制的后端保管密钥，并设置访问控制与调用限额。
