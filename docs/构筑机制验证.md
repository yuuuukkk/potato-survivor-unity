# 武器构筑 Play 验证

构筑在三格商店中按概率出现。购买只在本局解锁对应武器型号的构筑，不直接改变枪或近战武器。商店左下角的「武器构筑」打开独立页面；左侧选择持有武器，右侧查看该型号可用的构筑，并为这把武器装备、切换或卸下。同型号的另一把武器可以选不同构筑，不需要再购买同一构筑。不同型号不共用解锁。

现有分支：手枪/冲锋枪魅惑弹、各枪专属反弹/穿透/放大弹、剑气和直刺、拳套冲击、回旋镖回程强化。每个分支的伤害、攻速等代价都在卡面说明；SO 在 `UnityProject/Assets/_Game/Resources/Config/GameContent.asset`。反弹次数上限及放大尺寸上限在 `GameBalance.asset`。击退线圈仍是全局道具，未购买时攻击不附带击退。

## 快速测试

1. Play 选农夫，按 F1 打开 GM，直接给予一把土豆手枪和手枪构筑（例如 `pistol_ricochet`）。GM 的构筑操作是解锁，不是装备。
2. 结束当前波，进入商店，点「武器构筑」；左侧应看到手枪，右侧该构筑显示「装备」。选择后显示「已装备」。返回商店并进入下一波，观察手枪子弹碰边反弹。
3. 再拿一把手枪，解锁 `pistol_charm`，进入构筑页。第一把保持反弹，第二把选魅惑。被魅惑的普通怪应变粉、暂时不攻击玩家并转向其他怪；精英与 Boss 免疫。两把枪的表现应独立。
4. 获得加特林；手枪已解锁的构筑不能在加特林上装备。出售一把手枪不应删除解锁；再次取得手枪时仍可在构筑页选择已解锁的构筑。
5. 解锁 `pistol_big_round`，可与手枪的「弹道」分支并存，因为它属于独立「弹体」分支；放大应同时改变弹图与真实碰撞半径。选择「卸下全部」后，该把枪恢复原始效果，另一把手枪不受影响。
6. 解锁剑气、回旋镖回程强化，分别测试剑尖剑气和回旋镖去回程伤害差异。商店仍只有三格商品，锁定、刷新和购买正常。

这是人工 Play 检查清单；代码编译通过不等于上述画面与手感已经验证。
