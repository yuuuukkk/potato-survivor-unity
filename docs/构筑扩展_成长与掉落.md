# 构筑扩展：成长、掉落与战场变化

这份清单区分“已接入”和“设计候选”。商店先购买基础构筑，才会出现它的支线；支线可以再购买升级。同型号共享购买解锁等级，每一把武器独立装备基础构筑并选择支线、独立累计击杀。武器等级就是可用**基础构筑**槽数（当前 1–4 级对应 1–4 槽），支线不额外占槽；同一个基础构筑一次只走一条支线。数值留在 `GameContent.asset`，不把候选直接做成所有武器通用。

## 已接入本轮代码（等待 Unity Play 验证）

| 构筑 | 适用武器 | 收益 | 代价 |
| --- | --- | --- | --- |
| 生机种 | 土豆手枪 | 本枪补刀概率掉落可拾取的红色生机种；升级提高概率 | 直击伤害下降 |
| 狩猎生机 | 土豆狙击枪 | 狙击枪补刀概率掉落生机种 | 开火间隔增大 |
| 养锋 | 土豆大剑 | 本剑击杀累计层数，本局提升自身伤害 | 起始伤害下降，出售即失去成长 |
| 越打越热 | 冲锋枪 | 本枪击杀累计伤害层数 | 起始伤害下降 |
| 战斗记录 | 加特林 | 本枪击杀累计伤害层数 | 起始伤害下降，射速略慢 |
| 越转越利 | 回旋镖 | 本镖击杀累计伤害层数 | 起始伤害下降 |

生机种只在装备对应构筑的那把武器完成击杀时判定；它不是商店里的急救包。普通材料、经验和生机种是三种不同的掉落，不会把生机种算成材料。成长层数只作用于该武器实例，换一把同型号武器不会继承。构筑购买升级会提高生机种掉率或每层成长收益；具体值均可在 SO 调整。

本轮已做四棵示范树（待 Play 验证）：

| 基础构筑 | 二选一支线 | 差异 |
| --- | --- | --- |
| 土豆手枪·折射弹 | 连续折射 / 重击折射 | 覆盖更多目标但衰减；或次数不变、直击更重但射速慢 |
| 土豆手枪·生机种 | 丰收落种 / 饱满种子 | 生机种多但回复少；或掉落少但回复多 |
| 土豆大剑·养锋 | 速养锋 / 厚积锋芒 | 较快成型但每层弱；或成型慢、每层强 |
| 通用糖衣弹 | 甜蜜控制 / 余韵缠绕 | 魅惑概率优先；或持续时间优先 |

其他现有基础构筑目前仍只有基础效果与等级升级，尚未逐一补齐两条支线。商店不会在购买其基础之前出售支线。

## 刷怪节奏

旧逻辑是一波给定有限预算，耗尽后停止刷怪，倒计时可能空转；怪物类型来自固定权重池。现在初始预算仍控制开局密度，但会按 `GameBalance.asset` 中 `spawnBudgetSustainFraction` 持续补充，直到计时结束，同时保留场上最大数量限制。普通怪可在 `GameContent.asset` 中设置 `firstWave` 与 `weightGainPerWave`：默认第 1 波主要是追击怪，远程/自爆/坦克/分裂怪逐波加入。设持续补充比例为 0 可恢复旧行为。
