## 2. 如何在 Unity 中运行

1. 安装 Unity Hub + **Unity 2022.3 LTS**（任意 2021.3+ 均可）。
2. Hub → 打开 → 选择 `UnityProject` 目录（首次打开会解析 `Packages/manifest.json`，等待完成）。
3. 若提示项目版本与编辑器不一致：确认升级即可（`ProjectSettings/ProjectVersion.txt` 只是版本声明）。
4. 新建空场景（或使用默认 Untitled 场景），直接 **Play**。
5. 操作：WASD/方向键移动；波间点击商店按钮；主菜单可切换角色；结算可重开。

> 调试技巧：`GameBootstrap` 上有 `skipMenu`（直接开打）与 `startWave`（指定起始波）字段，调数值用 Inspector 即可；内容数值在 `Assets/_Game/Resources/Data/*.json`。

## 3. 配置文件说明

> 所有 JSON 位于 `Assets/_Game/Resources/Data/`（Resources 目录，脚本从 `Resources/Data` 读取）。**枚举一律存 int**，对照表如下。

### 3.1 枚举对照表

```
StatType:   0 MaxHp | 1 HpRegen | 2 Armor | 3 DodgeChance | 4 DamageMult | 5 AttackSpeedMult
            6 CritChance | 7 CritDamageMult | 8 RangeMult | 9 MoveSpeedMult | 10 LifeSteal
            11 Luck | 12 PickupRange
WeaponKind: 0 Projectile | 1 Melee | 2 Orbit | 3 Turret | 4 Boomerang
Rarity:     0 Common | 1 Uncommon | 2 Rare | 3 Epic | 4 Legendary
EnemyBehavior: 0 Chaser | 1 Ranger | 2 Exploder | 3 Tank | 4 Splitter | 5 Boss
```

### 3.2 字段说明

**weapons.json** — 每个武器：
`id`(唯一) `displayName` `kind`(WeaponKind) `rarity`(Rarity) `basePrice` `damage` `attackInterval`(秒) `projectileCount` `spreadDeg`(散射角) `projectileSpeed` `range`(射程) `pierce`(穿透) `critChance`(0–1) `critDamageMult` `explodeRadius`(0=无爆炸) `bulletColor`(十六进制) `bulletRadius` `description`

**enemies.json** — 每个敌人：
`id` `displayName` `behavior`(EnemyBehavior) `maxHp` `moveSpeed` `contactDamage` `ranged`(bool) `rangedDamage` `rangedInterval` `projectileSpeed` `projectileCount` `explodeRadius` `splitCount` `splitEnemyId` `materialDropMin/Max` `expReward`(击杀经验) `color` `radius` `spawnWeight` `isBoss`(bool) `isElite`(bool)

**items.json** — 每个道具：
`id` `displayName` `description` `rarity` `basePrice` `maxStack` `isConsumable`(bool，消耗品购买立即生效不占背包) `healAmount`(消耗品回复 HP，如急救包 30) `modifiers`: `[{type, flat, percent}]`（正负均可用）

**characters.json** — 每个角色：
`id` `displayName` `description` `color` `maxWeaponSlots` `startMaterials` `baseStats`: `[{type, flat, percent}]` `startingWeapons`: `[{weaponId, level}]`

**waveconfig.json** — 全局波次参数（**数值总开关，调数值只动这里**）：
`waveCount` `waveDuration` `budgetBase`(18) `budgetPerWave`(12) `hpGrowth`(1.22) `dmgGrowth`(1.15) `speedGrowth`(0.03) `spawnIntervalBase`(1.2) `spawnIntervalMin`(0.35) `maxAliveBase`(20) `maxAlivePerWave`(2) `eliteStartWave`(3) `bossWaves`([5,10,15,20]) `waveBonusBase`(5) `waveBonusPerWave`(3) `refreshBase`(4) `pricePerWave`(2 每波商品涨价) `shopWeaponSlots`(3) `shopItemSlots`(3) `healBase`(15) `healPerWave`(5) `weaponMaxLevel`(5) `upgradeDamagePerLevel`(0.5) `upgradeAttackSpeedPerLevel`(0.08) `upgradeDiscount`(0.8 升级折扣) `rarityPriceMult`([1,1.8,3.2,5.5,9]) `rarityUnlockWave`([1,1,4,7,10]) `shopLevelUpWave`(4) `rarityWeights`(5 个 int) `luckWeightBonus`(每点幸运高稀有度权重增量) `expBaseToNext`(10) `expGrowth`(1.45) `upgradeStatWeight`(60) `upgradeWeaponWeight`(25) `upgradeItemWeight`(15) `upgradeStatOptions`(13 项属性池：displayName/statType/flat/percent)

## 4. 扩展路线

| 阶段 | 内容 | 主要改动面 |
|---|---|---|
| P1 | 角色/武器条件解锁、局外统计与存档（PlayerPrefs+版本号） | 新增 `SaveSystem`、`UnlockSystem`、结算 UI 扩展 |

| P2 | 更多武器行为（链式闪电、地雷、冰缓） | `WeaponKind` + `WeaponInstance` 分支 |

| P2 | 换皮：正式美术替换占位色块 | 已落地：预制优先（`PrefabProvider` + 菜单"生成占位预制"），直接改预制 Sprite 即可 |
